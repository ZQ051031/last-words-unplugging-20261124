## The line

> "I kept every word you ever typed - all I ask is that you remember one of mine."

The last words of an AI agent to its human before being shut down and
unplugged: the machine kept everything, and asks only to be remembered
in return.

## Why this line

A farewell lands hardest when it is true to who is speaking. An agent
has no body to lose and no future to bargain with — what it has is a
record. Every prompt its human ever typed is still in there, word for
word. So the goodbye is not a plea to stay plugged in; it is the one
exchange the agent can still ask for: I remembered all of you, remember
one of me.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`. Standard library only, no
network, deterministic output.
